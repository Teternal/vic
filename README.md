# 儿童识字小天地

一个面向儿童的趣味识字 Web App，包含主题分类、生字卡片、收藏生字本和闯关测验等功能，帮助孩子在轻松的氛围中巩固汉字。

## 功能亮点

- **主题分类**：按照动物、水果、大自然、校园、传统节日等主题整理汉字，学习更有情境。
- **互动生字卡**：展示汉字、拼音、释义、笔画提示与示例句，可随机切换或顺序浏览。
- **收藏生字本**：一键收藏待复习的汉字，随时查看巩固。
- **语音朗读**：调用浏览器语音合成功能朗读汉字，帮助练习发音（需设备支持）。
- **测验模式**：根据提示选择正确汉字，记录正确率，提升学习趣味。

## 使用方式

1. 将仓库下载到本地后，直接用浏览器打开 `index.html`。
2. 在页面顶部选择感兴趣的主题，浏览、收藏生字。
3. 点击“开始测验”进入测验模式，完成后可点击“重新开始”再来一次。

> 温馨提示：建议在桌面浏览器或平板设备上使用，若浏览器不支持语音合成，则无法使用朗读功能。
